# 3D 月相與日月食科學探究實驗室 V2.0

繁體中文、國小高年級的本機互動教材。Vite + TypeScript + Three.js；不需帳號、後端或 API 金鑰。

## 開啟

需要 Node.js 22.12 以上（本次使用 24.15.0）。在本資料夾執行：

```powershell
npm ci
npm run dev
```

開啟終端機提供的本機網址，預設 http://127.0.0.1:5173/ 。不要直接雙擊 index.html。

```powershell
npm test                 # 科學純函式測試
npm run build            # 型別檢查及靜態建置，輸出 dist/
npm run preview          # 預覽正式建置
npx playwright install chromium  # 首次執行瀏覽器測試才需要
npm run test:browser      # 八任務流程＋590個無捲軸狀態＋純鍵盤流程
node tests/visual-browser.mjs  # 可選：視覺與WebGL失效還原
node tests/performance.mjs     # 可選：播放效能量測
```

瀏覽器測試需先另外啟動開發伺服器，固定 http://127.0.0.1:5173/ 。報告及截圖寫入 docs/。各腳本應依序執行，避免效能量測互相干擾。

## 已實作

- 可拖曳旋轉、縮放、俯視及側視的 3D 日地月場景，提供太陽置中公轉全景及地球置中月相近看。
- 地球23.44°傾斜自轉軸、黃道面法線與角度弧，以及「看自轉軸」放大按鈕。
- 一鍵連續公轉展示、前進四分之一年與畫面內暫停；已移除日月後方影錐線框。
- 同步地心月相、受光比例、地面放大觀測及月面亮側方向。
- 日偏食、日全食、日環食；半影月食、月偏食、月全食的幾何案例。
- 可調觀測經緯度、地平線、月球傾角及交點方向。
- 累積時間、四種播放速度、下一相位、接觸搜尋及快速播放食象攔截。
- 八項探究任務、分層提示、操作證據檢核、教師參考與自評。
- 本機保存、JSON／CSV 匯出、清除確認、儲存拒絕及無 WebGL 替代。

## 程式結構

- src/model.ts：公里／天／弧度的純幾何函式；不依賴 DOM 或 Three.js。
- src/scene.ts：3D 顯示、照明與日月食 shader、2D 觀測窗。
- src/main.ts：單一實驗參數來源、介面、播放、儲存及匯出。
- src/tasks.ts：八題任務、提示與參考解釋。
- tests/：模型與瀏覽器驗證。
- docs/scientific-model.md：模型、公式、簡化與來源。
- docs/teacher-guide.md：教學路徑、作答規準、八題參考。
- docs/acceptance.md：A01～A18 的實際驗收與限制。

## 使用與資料

預設暫停，減少動態偏好下不自動播放。重要操作可用鍵盤；3D 鏡頭亦有按鈕替代。
作答儲存於目前瀏覽器的 localStorage（moon-lab-v2）。不同瀏覽器、連接埠或清除網站資料會影響保存；請匯出備份。
JSON 保存完整作答與模型參數；CSV 每筆證據一列，沒有證據的題目也保留作答。
內建測試匯出檔僅含自動測試文字，沒有學生個資。

## 已知限制

這是圓軌道與固定交點的教學模型，不提供實際日期、所在地食象預報或真實星圖。3D 天體大小與距離分別縮放，兩種視角都由同一公里計算模型轉換；地表及月面紋理是自製程序圖樣，不能用來辨識真實地形。
一年比較採 0.02 天取樣，可能漏掉極短的擦邊事件；下一食象與播放攔截則使用極值搜尋及接觸二分法。
有限太陽距離下，黃經差90°的弦月亮面約50.1285%，因此原規格「50% ±0.1個百分點」不能在保留此幾何模型時照字面通過。詳見驗收。
無頭 Chromium 的軟體 GPU 效能不代表真實平板；桌面播放目標及實機效能的未通過事項請見驗收紀錄。
沒有建立遠端儲存庫、提交、推送或公開部署。工作區原有修改未變更。

## 2026-10-19 視角修訂

預設太陽置中，按「播放地球公轉」以100天／秒連續展示；「前進四分之一年」可比較90°公轉位置。公轉展示會取消食象自動暫停，可再自行勾回。
按「看自轉軸」會暫停、切到地球近看並放大；青線為23.44°自轉軸，灰虛線為黃道面法線。載入食象案例會切到地球置中方便觀察。
修訂驗證見 docs/revision-notes.md、docs/revision-view-report.json。

## 2026-10-20 單畫面 RWD

單一入口、四個模式，每個模式都固定在目前視窗內，沒有頁面或面板捲軸。桌面同時顯示3D及右側觀測／設定／地點；手機一次顯示3D、觀測、設定或地點其中一區。設定以軌道／案例／顯示分組，地點以經緯度／交點分組。

探究挑戰以預測、證據、解釋、檢核四步操作。長作答每段最多36字，可新增或翻回前段；資料仍完整串接保存與匯出。證據一筆一頁，回饋及比較文字可逐段閱讀。短橫向視窗會再將選擇題及文字解釋分開顯示。訊息列的完整內容可按「訊息詳情」。

支援並實測1440×900、1024×768、390×844、320×568、844×390。最新報告及截圖見 `docs/no-scroll-rwd.md`、`docs/no-scroll-audit.json`、`docs/no-scroll-flow.json`。
