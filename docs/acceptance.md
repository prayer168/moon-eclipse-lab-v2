## 效能實測

Windows桌機：Intel Core i5-11500、12邏輯執行緒；系統顯示介面 Intel UHD Graphics 750。但本次無頭 Chromium 141.0.7390.37 實際使用 ANGLE／Vulkan SwiftShader **軟體GPU**，不是硬體顯示卡效能。量測為每個視窗播放0.1模擬天／實秒，暖機2.5秒後記錄180個rAF；render loop每個rAF繪製3D，科學及2D觀測約每33ms更新。數值是主迴圈時脈，並非GPU timer。

|視窗|播放狀態|量測秒數|FPS|3D畫素倍率|Draw calls|
|---|---|---|---|---|---|
|1440×900|播放|4.628|38.9|0.50|13|
|1024×768|播放|4.372|41.2|0.50|13|
|390×844|播放|3.504|51.4|0.50|13|

靜止場景主迴圈三種視窗約60FPS，詳見browser-report.json。播放中的桌面沒有達到50FPS目標；1024視窗超過30FPS，但這不等於實體平板已驗證。自動降畫素倍率至0.5、減少地球繪製呼叫及改進月面像素迴圈已完成；剩餘限制是軟體GPU與逐次畫面更新成本。正式課堂前仍應在實際投影機／平板試跑。

## 驗證檔案與重現

- unit-report.json：15項模型測試。
- browser-report.json：案例、儲存、匯出、重設、搜尋、高速攔截及三種視窗。
- task-report.json：八個任務達成路徑及附加操作。
- visual-checks.json：亮側、拖曳、WebGL失效及還原。
- keyboard-report.json：純鍵盤完成任務4。
- performance-active.json：播放效能原始量測。
- dependency-audit.json：依賴稽核結果。
- preview-1440.png、preview-1024.png、preview-390.png、preview-final.png：中性初始狀態截圖。
- case-*.png：六種食象案例截圖。
- test-export.json／csv：自動測試文字匯出範例，不是學生資料。

先執行npm run dev，再依README順序執行tests/*.mjs；瀏覽器案例圖使用獨立測試情境，本機真實使用者作答不會被這些無頭測試情境修改。

## 剩餘限制

1. A01的原數字容差與有限太陽距離模型有小幅衝突；目前保留物理公式而非強制把弦月設成50%。
2. A17桌面軟體GPU播放未達50FPS；實體平板、iOS Safari及觸控雙指操作尚未驗證。
3. 一年比較是0.02天取樣統計，可能漏掉極短擦邊事件，介面已揭示解析度；下一食象搜尋與高速攔截採極值及接觸求根。
4. 圓軌道、固定交點、近似影錐、大氣顏色示意、程序地形，不是星曆與觀測預報。
5. 無WebGL時保留2D觀測與數值，但無法提供3D旋轉。
6. localStorage依瀏覽器／來源保存，無跨裝置同步與匯入回復介面；可匯出完整JSON留存。
