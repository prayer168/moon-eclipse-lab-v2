# 真實地球地圖修訂驗收

日期：2026-10-20（臺灣時間）。版本：Natural Earth 真實海陸平面貼圖與七洲五洋。

## 完成內容
- 使用 Natural Earth 1:50 million 陸地、湖泊、冰川多邊形，轉為4096×2048貼圖（119551 bytes），取代程序生成海陸。自然色為示意配色；無雲、無立體地形，非衛星照片。
- 七大洲、五大洋、臺灣繁體中文標示，放大依球面朝向與文字避讓顯示。標示點與地圖共用經緯度及地球姿態，背面不顯示。
- 地球近看從亞洲臺灣開始，拖曳與縮放可查看各地；近看進入全螢幕仍保留近看，播放時追隨地球位置。點標籤顯示代表點經緯度。
- 設定→顯示新增全亮地圖閱讀，預設關閉；明示非晝夜照明，不改動科學數值。
- 短橫向畫面近看時收起次要時間軸／讀值，保留播放及場景控制；來源說明短畫面收起，完整內容見教師與模型文件。

## 修正過程與限制
測試曾找到短橫向畫面設定裁切、地理標籤遮擋重設按鈕；已縮短閱讀說明並讓工具列優先，重跑通過。狹小畫面為避免重疊可能不顯示所有朝向鏡頭的名稱，需放大或轉動。比例尺1:5000萬的海岸線已概化，島嶼與地形細節有限；不供測繪。未做政治國界、洲洋範圍查詢或海底地形。冰川為來源靜態資料，不代表所選日期海冰狀態；沒有即時地表或天氣。未測Safari／Firefox與實體平板。
