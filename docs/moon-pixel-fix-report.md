# 月面像素一致性修正驗收（2026-10-20）

## 原因與修正
原觀測窗以96×64三角網格及MSAA繪圖；CPU備援則逐像素求解析正射球面。相同螢幕座標會得到略不同的球面法線、經緯度及貼圖取樣位置，細緻月面與邊緣放大了差異。擴大同條件對照時，舊網格在基本圖最大差異18/255、4K最大57/255，不能只把原本三點檢查的門檻從6放寬到7。

觀測窗改為解析正射球面shader，與CPU共享像素中心、視角、本體姿態、球半徑、太陽方向、影錐、貼圖與取樣規則。太空主場景仍用3D球體網格。明確指定NoColorSpace、北向上、經度重複、緯度夾限及雙線性取樣。月相／食象純函式未修改。

另修正測試固定條件：等待指定LOD後擷取同一份解碼貼圖，採單一Vite測試模組入口，避免HMR查詢版本產生不同的月面資產儲存。每個案例使用固定Params，不依賴正在播放的介面或當下裝置時間。

## 限制與交付
逐像素一致不代表月面模型是測繪或光譜級精確：仍忽略坑緣自遮蔽、採球形輪廓、NASA合成資料、教學近似月食紅化。解析窗以像素中心切割圓盤，不用MSAA，輪廓可能有一像素階梯。本次未重測FPS，也未實測實體手機或平板。上線檢查結果另存moon-pixel-public.json。同步到指定Google Drive本機資料夾，伺服器端同步狀態不由本工具確認。
