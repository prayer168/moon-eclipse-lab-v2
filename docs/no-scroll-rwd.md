# 單畫面 RWD 修訂與驗收

日期：2026-10-20。依使用者要求，所有模式改為單一視窗內的響應式介面，沒有頁面、側欄、作答區或對話框捲軸。

## 介面

- 同一份index.html內切換月相、日食、月食、探究，沒有另外開啟內容頁面。
- 桌面：3D及時間軸在左，右側切換地球觀測、實驗設定、觀測地點。
- 手機：以3D實驗、觀測、設定、地點分區切換，一次顯示可完整容納的一區。
- 設定分軌道、案例、顯示；地點分經緯度、交點。沒有以縮小全部文字的方式硬塞。
- 探究四步為預測、證據、解釋、檢核；短橫向視窗會再切分選擇題及文字解釋。
- 每段作答最多36字，可新增及修改前後段，完整文字仍保留與匯出。
- 證據一筆一頁，可刪除與翻閱；比較結果、回饋、說明以分段方式呈現。
- 下方訊息列可開啟完整訊息對話框，沒有因省略顯示而失去內容。

## 實際驗證

1. 19項科學與顯示座標單元測試通過；天文計算規則未變更。
2. 無捲軸檢查590個狀態，涵蓋1440×900、1024×768、390×844、320×568、844×390。
3. 檢查四個模式、設定分組、八題四步、證據／解釋／檢核子區、說明及清除對話框。
4. 以長預測、長解釋、長回饋、30筆證據及長比較結果測試，未發現可捲動元素、超出畫面的控制項、被裁切的主面板或文字輸入溢位。
5. 八個探究任務實際走過預測、操作、證據、解釋、自評及檢核；保存、JSON／CSV匯出、取消清除、手機分區、說明、教師參考、儲存拒絕與無WebGL替代也已驗證。
6. 以Tab／Enter／方向鍵／Space完成任務4，沒有使用滑鼠。
7. TypeScript型別檢查與Vite正式建置通過。
