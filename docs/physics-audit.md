# 物理真實性與可靠性檢核（2026-10-20）

## 實際使用工具
1. Vitest 4.1.11：純函式與回歸測試，不是專業星曆引擎。
2. 自編TypeScript牛頓二體RK4數值積分器：獨立於克卜勒解法，以反平方引力積分一年，12000等步長，120個位置交叉比對。
3. 解析物理不變量檢核：克卜勒方程殘差、比能、比角動量、年週期閉合。
4. TypeScript 5.9.3／Vite 7.3.7：型別檢查與正式建置。
5. Codex in-app browser（Chromium）DOM與畫面驗證：近日遠日定位、全螢幕、鍵盤、七案例、無捲軸尺寸。
6. NASA Earth Fact Sheet及JPL公式文件：外部常數與方法對照。

未執行SPICE、Horizons星曆比對、第三方物理認證或真實觀測驗證；沒有把瀏覽器渲染當作物理檢驗。

## 科學修正
- 地球由勻速圓軌道改為太陽在焦點的固定橢圓：a=149600000km，e=0.0167，T=365.256天。月球維持27.3217天圓軌道教學近似。
- t=0為自訂近日點，不對應實際日期。M均勻增加，E由Newton迭代解克卜勒方程，位置與速度由同一E推導。
- 近日147101680km、30.29km/s；遠日152098320km、29.29km/s。NASA資料約147.095／152.100百萬km；採用的四捨五入常數造成小幅差異，非精密星曆常數。
- 日地顯示位置使用同一均勻比例；軌道離心率不誇張。月球距離和天體半徑為教學比例，不能從畫面量測真實半徑或距離。
- 月食shader原使用固定日地距離，現已改為當下距離，與分類共用模型。
- 月食案例以滿月實際相位根定位；不能再把平均朔望月除二當作精確滿月。
- 四分之一年不等於90度；逐次朔望週期非固定29.5306天。一般月相不由地球影子造成。

## 實際結果
- `npm test -- --reporter=default --reporter=json --outputFile=docs/physics-unit-report.json`：22/22通過（3個測試檔）。
- 解析橢圓對獨立RK4一年最大位置差0.0000154075km；通過0.01km門檻。這只驗證相同二體假設下的一致性，不是與真實地球的誤差。
- 方程殘差<1e-12rad；能量、角動量及週期相對值10位小數檢核通過，包含負時間及超過兩年的時刻。
- 月相公式、傾角、恆星月／平均朔望月、下一相位、日食相切與分類、月食分級、地平線與極點有限值、400天食象搜尋回歸通過。
- 正式建置與型別檢查通過。
- 瀏覽器近日／遠日按鈕實測：0天147.102百萬km／30.29km/s；182.628天152.098百萬km／29.29km/s。
- 七個案例的全球分類見`physics-cases.json`。日偏食教師案例是「當地偏食」，同時全球其他地點可能全食；此差異符合模型，單元測試亦檢查當地偏食。
- 全螢幕隱藏控制、標籤、星空、軌道、自轉軸與觀測點，只保留三天體。實測Space、+、方向鍵、Esc返回，恢復先前分區。保留OrbitControls旋轉與縮放處理。
- 1440×900、1024×768、390×844瀏覽器視窗無頁面溢出；見`physics-rwd.json`。未重做上一版本590狀態完整稽核，未實測真實觸控硬體。

## 限制與教學判定
適合說明月相、視圓盤遮掩、傾角、交點、近日遠日及速度變化的教學幾何；不能用來預報日月食時間、地點或精確食分。
地球與月球不是完整互相耦合三體積分；不含月球橢圓／近地點進動、交點退行、攝動、章動、歲差、光行時、地球扁率與地形、視差以外的精密觀測修正、大氣折射及真實大氣光度。影錐採球體近軸幾何，半影亮度及紅月為概念著色，非光度模型。
近日點方向與自轉軸方向採教學座標，未校準曆日與季節，不能用它推斷近日點的實際季節。八等分月相名稱是區間名稱，精確弦月須讀相位角或使用下一主要月相。
主視窗從任意鏡頭看見的受光面與地球觀測窗可能不同；地球月相由模型計算，不隨自由鏡頭改變。
舊localStorage作答仍保留，但先前證據是舊模型結果；修訂後比較實驗應重錄。此次未新增效能數據；不宣稱改善幀率。
