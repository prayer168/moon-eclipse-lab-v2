## 發現並修正

1. 瀏覽器Intl農曆在2057-09-28與HKO公布表差一天。已移除對Intl農曆的依賴，使用官方200份年度對照表重編的月首，並留存來源SHA256；不是硬改天文月相來符合農曆。
2. 日期設定在844×390曾被裁切。短橫向改為日期時間／模式與視角兩頁，保留操作。
3. 擴大620狀態稽核又發現短橫向的月相／日食／月食三個觀測窗有內容裁切，已精簡重複標題並調整文字及間距。修正前摘要見date-layout-fixes.json，複查620狀態全部通過。
4. 手機農曆日期末字曾換行，已加寬透明日期區並加上單行驗收。短畫面月面原有註記可能覆蓋月亮，已依可用高度調整月面與註記位置，短窗只保留外部必要說明。
5. 任務3舊測試以平均朔望月倍數當新月，與橢圓軌道不完全一致。改為透過下一主要月相實際定位，八題全部通過，沒有放寬操作判準。
6. 月相名稱原先45°分段會把較大的盈凸月標為上弦。現在主要相位用相對黃經±1°教學容差，其餘依盈虧方向分類；精確時刻仍以求根／星曆搜尋為準。
7. 真實日期的下一食象定位中心時刻，已將自動暫停文字與訊息同步改為中心時刻，避免誤稱接觸起始。

## 科學資料與可靠性範圍

- Astronomy Engine固定2.1.19，提供日地月向量、地球觀測點及IAU姿態。3D、月相、地平線與日期共用同一t，不替教學第0天套上假的西元日期。公里換算採149597870.7km/AU，座標基準為J2000黃道座標。
- 星曆接線測試包含向量照明與Illumination的比例比較、ObserverVector幾何與Equator/Horizon另一計算路徑比對、已知2024年4月新月與9月滿月、下一相位及下一食象日期。這些是接線與數值一致性檢查，不是完整獨立星曆認證。
- HKO公開曆表以月首二分查詢，不用固定29.53天循環。14個選定官方日期測試涵蓋1901／2100、春節、閏六月、2033閏十一月，以及2057等午夜新月邊界；生成器另完整核對73,049個日期的轉換連續性。
- 例：2024-09-17晚間雖為農曆八月十五，仍由天文向量計算受光，不強制畫成100%滿月。

已知限制：裝置時鐘錯誤會影響現在模式；不使用伺服器校時。時間一律UTC+08:00，不套用歷史夏令時間。農曆採下載時HKO公布表，未來接近午夜的新月／節氣可能因精度修訂有一日差異，不宣稱各時代地方曆書均相同。
地表是球體／程序紋理示意，天體大小與地月顯示距離放大；月球軌道線是瞬時軌道面的教學圓環。食象繪圖與當下分類仍採幾何近似，非精密接觸時刻或食分預報；不計天氣與雲量，地平線可見性未加大氣折射。
尚未驗證實體手機／平板、Safari、Firefox；未逐日比對JPL Horizons，也未重新量測FPS。這些項目未標示為通過。
