# 公轉視角、自轉軸及線框修訂

日期：2026-10-19。依使用者要求改善地球公轉可見性、顯示傾斜自轉軸及移除地月後方殘影。

## 完成內容

- 原本一直以地球置中，現預設太陽置中，地球依模型時間繞太陽移動。保留地球置中月相近看。
- 新增「播放地球公轉」，以100模擬天／實秒持續播放，取消食象自動暫停；可用畫面內暫停。一般播放仍可勾選食象自動暫停。
- 新增「前進四分之一年」，每次增加91.314天，地球公轉位置前進90°。
- 新增實際3D地球自轉軸、南北極端點、黃道面法線、23.44°角度弧與標籤。軸在世界座標中保持固定方向。
- 新增「看自轉軸」近看按鈕，自動暫停、放大並把主畫面捲到可見位置。
- 移除天體後方所有影錐線框及光線束；保留公轉軌道、交點線和天體表面日月食遮蔽。
- 切換視角只影響顯示座標，不改變模型時間、天體位置計算、月相、食象或作答。
- 載入食象案例自動切換地球近看；重設回公轉全景並保留作答。

## 範圍與限制

天體大小及距離仍為教學示意；公轉全景為了容納整圈軌道，地球看起來較小，可用「看自轉軸」放大。23.44°指三維軸與黃道面法線夾角，經鏡頭投影後不一定呈現同樣螢幕角度。
本次未重新量測效能或實體平板；原驗收A01及A17的部分通過限制仍保留。修訂未公開部署。
