# 天文模型與簡化

## 單位、週期與座標

內部單位為公里、天、弧度。黃道面為XY，黃道北方為+Z，北方看公轉為逆時針。太陽在原點，地球以半長軸149600000km、離心率0.0167、週期365.256天依克卜勒方程繞日，太陽位於焦點。第0天為自訂近日點紀元。月球以預設距離384400km、慣性週期27.3217天繞地；平均朔望週期約29.5306天；橢圓軌道使逐次相位間隔不同，實際相位使用位置求根。

月球軌道的參數式先繞X軸傾斜i，再繞Z軸旋轉升交點Ω。預設i=5.145°、Ω=0°。t=0時預設軌道在交點與新月附近，因此可能發生日食；這是任意的模型相位零點，沒有對應真實曆日。

## 月相

月球看向太陽及觀測點的單位向量為u與v，受光比例k=(1+u·v)/2。主數字及預設放大圖使用地心；當地夜空使用地表觀測點及地表受光率，兩者有視差。名稱依相對黃經和盈虧方向判斷：主要相位在0/90/180/270°附近±1°標為新月／上弦／滿月／下弦，其餘分別為眉月／盈凸／虧凸／殘月。名稱仍是教學容差區間，精確相位時刻須求根。

新月附近也可能有少量亮面，這不是月食。地球影子只在月食時額外使月面變暗；不改寫月相幾何受光比例。

日地距離有限時，黃經差90°不代表月球位置的相位角恰好90°。共面相對黃經90°（以求根定位，而非平均朔望月除四）時：

k = (1 + r / sqrt(D²+r²)) / 2 ≈ 0.50128475。

測試保留這項差異，不把結果硬改成50%。

## 日食與全球判定

地表觀測點O看向日月，分別計算asin(R/d)視半徑及中心角距。角距小於視半徑和才重疊；完全包含時依日月視大小區分全食與環食。月球必須在太陽之前，且在同一個視線半球。

全球分類不是把地心分類當成地表分類：先以影軸與地球距離排除無食，再利用日月地中心的軸對稱，在朝日半球的一條大圓子午線搜尋圓盤重疊最大的地表點，使用32次三分搜尋。這是教學數值解，沒有納入扁球與月緣地形；極接觸邊界以角度1e-10弧度容差處理。

「當地幾何」即使在夜側仍可能算出視線延伸上的遮蔽，但另外顯示太陽是否在地平線上；只有太陽高度>0°才列為當地可見。這避免把全球發生、當地幾何及可見性混為一談。

## 月食與影錐

地球背日方向為影軸。月球中心軸向距離x、偏離影軸距離d；地球本影半徑Ru=Re−x(Rs−Re)/D，半影半徑Rp=Re+x(Rs+Re)/D。此為小角度影錐近似。以月球圓盤與影區相交分類半影、偏食與全食，容差1e-6km。

3D地球shader按真實位置計算日月視圓盤相交面積，投影為日食暗區。月球shader及2D月面以球面位置與地球影錐關係顯示遮蔽。半影亮度採簡化係數，全食紅光是大氣折射的概念著色，並非輻射傳輸計算。

3D影錐線框與後方光線已移除，保留天體表面的實際遮蔽效果。預設太陽置中，以固定顯示半徑105呈現地球繞日；地球置中近看則將地球放在原點。兩者皆由同一公里座標模型映射，顯示大小與距離不同於真實比例。分類、受光與地面視窗使用公里計算，不使用示意位置、陰影貼圖或畫面像素。

地球自轉軸的世界方向固定為[0,−sin(23.44°),cos(23.44°)]，相對黃道面法線傾斜23.44°，公轉中保持平行，不隨地球自轉或公轉轉向太陽。青色圓柱穿過南北極，灰色虛線顯示黃道面法線，金弧示意夾角。

## 地面觀測

地球以0.9972696天自轉，軸傾角23.44°。經緯度轉為世界座標，再計算日月視線與天頂方向的內積，得到高度角。顯示方向以天頂在目標切平面的投影為上方；一般放大模式以黃道北方為上方。太陽正對天頂時，畫面方向在數學上沒有唯一選擇，採穩定備援方向。

地球及月球以程序紋理示意；地球圖樣與自轉同步，月球紋理採朝地同步自轉近似。沒有真實地理海岸、天平動、恆星、赤經赤緯讀值或大氣折射。天空模式是目標放大窗，不是完整天球投影；底線只是地平線提示，可見性以高度文字為準。

## 時間與事件

所有位置由同一tDays推導；播放速度只控制每實秒流逝的模型天數。使用下一主要相位時，以黃經差二分求根。食象搜尋在每次朔望附近尋找遮蔽裕量極大值，再二分接觸時刻，避免固定取樣漏過短事件；受限於浮點容差，不能當成精密食象接觸預報。

播放開始先快取下一事件，時間跨越時停在接觸之後極小量；不受每畫格跨度影響。一年比較是明確標示0.02天解析度的另一項教學計數，包含觀察起點正在進行的事件，可能漏掉極短擦邊事件。

## 月球姿態與沉浸式HUD
月球姿態現在以獨立自轉極軸及27.3217天轉角計算，不再把月球的自轉軸指向地球。月球極軸相對黃道北方1.54°，與軌道法線分列黃道北方兩側；固定交點時極軸在時間中維持方向，忽略18.6年進動與物理天平動。完整座標定義與驗證見 immersive-report.md、src/orientation.ts。

## 真實日期星曆模型
`Params.model='ephemeris'`時，t為自2000-01-01 12:00 UTC起的UT天數，使用Astronomy Engine 2.1.19。Date.now只決定即時模式的t，與加速播放分開；模型、畫面、觀測及日期均讀取同一t。
HelioVector(Earth)與GeoMoonState轉至固定J2000黃道座標；km換算使用149597870.7km/AU。地月狀態叉積導出瞬時軌道面，避免沿用任意5.145°或固定交點。3D地球公轉線按所選年取樣，近日遠日標記由SearchPlanetApsis計算；月球軌道線是當下軌道面上的教學圓環，不是精密未來軌跡。
IAU月球極軸與轉角由RotationAxis計算。地球姿態及地表觀測點由ObserverVector轉換；高度與方位由同一地表基底推導，未加入大氣折射。地心與地表受光率皆由太陽方向、各自觀測方向的內積計算；夜空下地平線提示與受光分開。
下一主要相位改用SearchMoonQuarter；下一食象用SearchGlobalSolarEclipse／SearchLunarEclipse，定位中心時刻，非接觸起始。畫面當下分類與陰影仍採共享球體／近軸影錐幾何，不宣稱食分或接觸時刻具專業預報精度。
舊有探究模式維持克卜勒地球橢圓與月球固定交點圓軌道，不對應曆日。進入任務切至探究模式，不讓假設傾角被混入真實星曆。

## 農曆資料與時間基準
農曆使用香港天文台1901–2100共200份年度文字對照表；建立2475個月首，查表得到大小月、閏月、春節年界。生成程序檢核全範圍73049日連續及月長29/30日，來源SHA256記錄於hko-calendar-validation.json。首筆1900年十一月月首由1901-01-01對照表的「十一」日反推，用於邊界查表。
資料在建置時隨網站打包，執行時不需要外部API。固定臺灣標準時間UTC+08:00換算公曆日，不套用歷史夏令時間。農曆年使用對照表農曆年及干支，與西元春節前的年份可能不同。
先前嘗試的Intl Chinese Calendar在2057-09-28與HKO表差一日，已完全移除，改用官方月首資料，沒有靠日期特例硬改天文月相。HKO亦提示遠未來接近午夜的新月／節氣日期可能有一日不確定性；本工具依下載日的公布曆表呈現。
來源及重建： https://www.hko.gov.hk/tc/gts/time/conversion1_text.htm ；先執行tools/download-hko-calendar.ps1，再執行tools/build-hko-calendar.py。Astronomy Engine介面與原始碼： https://github.com/cosinekitty/astronomy 。
