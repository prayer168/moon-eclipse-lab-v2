# 教師操作指南

對象：國小高年級。建議兩節課，每節40分鐘；教師投影示範後，小組使用桌機或平板。全程不需學生姓名或登入。

## 第一節：照明與觀點

1. 先請學生預測「半亮月面每個月出現幾次？」
2. 俯視3D模型，播放或按下一主要月相，同時比較地球觀測窗。
3. 完成任務1及2；對照受光比例、相位名稱與月食分類。
4. 用0°與5.145°比較新月附近，討論新月為何不一定日食。

## 第二節：影子與證據

1. 載入日全食、環食、月偏食、月全食案例。請學生先指出日月地排列。
2. 同一日全食下改變經度，查看全球與當地差異，以及地平線文字。
3. 進行一年比較；保持起始時間、交點方向、距離相同，只改傾角。
4. 小組以主張、證據、推理分享，匯出作答備份。

## 八題操作與參考

|任務|操作路徑|應理解的解釋|
|---|---|---|
|1 半亮月面|載入月全食共面案例，按下一主要月相找到上下弦，各記錄一次|相似受光比例可以有不同盈虧方向|
|2 月相與地影|記錄至少三種月相，關閉輔助線比較|一般月相不是地球影子造成|
|3 新月與日食|保持交點0°，分別以0°、5.145°記錄三次新月；每四次主要相位回到新月|新月還要接近日地連線才可能食象|
|4 月全食|載入月全食案例並記錄|太陽—地球—月球，月球完全進入本影|
|5 當地可見|載入日全食記錄，再保持時間改經度180°並記錄|陰影範圍及地平線共同限制可見性|
|6 傾角|按一年比較，閱讀各組起點、觀察窗、距離、交點與事件段數|控制其他變因，在同一觀察窗比較；不由單次事件歸納|
|7 速度|選擇兩種天／秒，各留下一筆證據，再按同一相位比較|速度改變呈現快慢，不改變模型週期或相位順序|
|8 全食與環食|各載入並記錄日全食與環食，比較案例距離|月球視大小隨距離而變，實際半徑沒有突然改變|

每題必須先寫預測才能記錄證據。系統驗證選項與操作紀錄條件，不以關鍵字評分文字推理。完成提示中的「客觀與操作檢核完成」不等於老師已認可解釋。

## 評閱規準

- 主張：直接回應問題，指出可檢驗的現象。
- 證據：引用具體時間、傾角、相位、食象或地點紀錄。
- 推理：將證據連結到照明、相對位置、陰影、視大小或地平線，而非只重述結果。

可各給0～2分；頁面自評只是提醒學生檢查是否具備三項，沒有自動判定推理正確。

## 操作與備份

3D拖曳旋轉、滾輪／雙指縮放。鍵盤使用Tab移動焦點，Enter啟動按鈕，方向鍵調整滑桿及選單。按俯視／側視／重設視角可回復方向。自由鏡頭改變不會改變地球所見月相。

時間軸為35天一窗，可前後切換，累積天數不歸零；拖曳時間會暫停。最快速度會在下一次食象接觸附近自動暫停，可切慢速觀察。地面方向切換也會暫停。預設臺灣23.5°N、121°E；老師案例使用各自幾何最合適的地點，請看經緯度與距離標示。

重設實驗保留作答；重試本題保留證據，可逐筆刪除。清除全部作答需要再次確認，取消則保留原資料。請在下課前匯出JSON或CSV；JSON保留完整結構，CSV適合試算表閱讀。瀏覽器拒絕儲存時仍可匯出，重新整理前務必下載。

## 教學限制

請用模型解釋條件，不用它查詢真實日期的日月食。程序地表圖樣不是真實地圖，影錐線框不能直接量測。月面放大窗即使目標在地平線下仍保留形狀以供比較，旁邊明示當地不可見。不得把放大窗當成當地肉眼天空照片。

目前已測桌面瀏覽器模擬三種視窗，尚未用實體平板驗證觸控及課堂網路。顯示品質會自動降低以維持互動，文字控制不受此影響。

## 公轉與自轉軸的新增操作

預設「太陽置中・公轉全景」。按「播放地球公轉」連續觀察，約3.65實秒繞行一圈；按畫面右上的暫停可停住。想逐步比較時按「前進四分之一年」，每次前進約91.314天。

按「看自轉軸」會暫停並放大地球；對照青色自轉軸、灰色黃道面法線與金色23.44°夾角。公轉全景中軸的空間方向保持平行。旋轉鏡頭時螢幕上的投影角不一定等於23.44°，標示指的是三維實際夾角。

月相或食象需要近看時可切換「地球置中・月相近看」；食象案例會自動切換。原本看起來像殘影的線框已移除，不影響日月食幾何及月面遮蔽。公轉展示取消「食象開始時自動暫停」，一般探究可自行勾回，重設實驗也會還原勾選。

## 單畫面操作（2026-10-20）

本版不捲動頁面。手機先選模式，再用「3D實驗／觀測／設定／地點」切換畫面；桌面使用右側分區。設定中的軌道、案例、顯示各自成組，地點分經緯度及交點。所有切換保留同一份實驗時間與作答。

探究分四步：1預測、2證據、3解釋、4檢核。證據步驟的「回到實驗」可操作變因，之後切回探究再記錄當下。證據可逐筆翻頁、刪除；比較結果逐段查看。檢核步驟有自評、回饋、參考三個分區。短橫向畫面會將選擇題與文字解釋拆開，避免裁切。

每段文字最多36字，按「後段／新增」繼續，按「前段」修訂；保存及匯出仍為完整文字。長訊息可按下方「訊息詳情」。說明與教師參考也能翻頁閱讀。


## 全螢幕與近日／遠日點
全螢幕只保留三個天體。拖曳旋轉、滾輪或雙指縮放，空白鍵或雙擊播放／暫停，左右鍵前後0.25天，+／−縮放，R重設視角，Esc返回。未支援原生全螢幕時使用瀏覽器內滿版。
「實驗設定→公轉」可按近日點、遠日點，讀取日地距離與速度。近日較快、遠日較慢，真實離心率很小，勿將軌道畫成明顯扁橢圓。四分之一年不等於剛好90°。近日點不是北半球夏天的原因；季節主要由自轉軸傾斜造成。
第0天是自訂近日點，與真實日期、歲差及月球曆不對應；原作答保留，但舊證據採舊圓軌道，教師比較時須重新記錄。


## 最新沉浸式展示配置
全螢幕已改為保留軸線與軌道面，取代先前純三天體畫面。右上月相採「地心視角・黃道北向上」，與地表觀測方向不同。
請先以1鍵（0.1天／秒）看地球自轉，再以2鍵（100天／秒）看公轉，提醒高速影像可能有混疊、不能用來判讀自轉方向。月球自轉一圈與公轉一圈皆27.3217天；月軸相對黃道北方固定傾斜1.54°，與預設月軌道法線夾角約6.685°，不要把1.54°標成相對月球軌道面。
全螢幕不自動攔截食象，方便連續演示；退出後恢復一般模式的食象攔截設定。靜止長按0.9秒或Esc退出，拖曳及雙指手勢會取消長按計時。
建議學生先預測受光比例，再拖曳主鏡頭，說明右上地球所見月相為何不因太空觀察角度改變。
